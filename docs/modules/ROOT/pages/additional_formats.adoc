= Additional Formats

Some formats may require additional support libraries to be included in your project. Below are some common formats and the corresponding libraries you may need:

== XZ Support

XZ support needs `org.tukaani:xz` on the class path or module path. There is no separate Compress4J artifact; the former `compress4j-xz-support` capability and its `io.github.compress4j.xz` automatic module name no longer exist, so remove them from your build and `module-info.java`.

On the module path, `org.tukaani.xz` is not resolved automatically. Add `requires org.tukaani.xz;` to your module, or start the JVM with `--add-modules org.tukaani.xz`.

[tabs]
====
Maven::
+
[source,xml]
----
<dependency>
    <groupId>io.github.compress4j</groupId>
    <artifactId>compress4j</artifactId>
    <version>YOUR_VERSION</version>
</dependency>
<dependency>
    <groupId>org.tukaani</groupId>
    <artifactId>xz</artifactId>
    <version>YOUR_XZ_VERSION</version>
</dependency>
----

Gradle Groovy::
+
[source,groovy]
----
dependencies {
    implementation 'io.github.compress4j:compress4j:YOUR_VERSION'
    implementation 'org.tukaani:xz:YOUR_XZ_VERSION'
}
----

Gradle Kotlin::
+
[source,kotlin]
----
dependencies {
    implementation("io.github.compress4j:compress4j:YOUR_VERSION")
    implementation("org.tukaani:xz:YOUR_XZ_VERSION")
}
----
