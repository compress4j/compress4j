= Unix compress (.Z)

NOTE: Read-only: Compress4J can extract this format but cannot create it.

Unix compress support needs no extra dependency. The `.Z` format has no end marker, so a truncated file decompresses to a shorter output without an error; `.tar.Z` extraction still fails on a truncated archive because the tar entries are incomplete.
