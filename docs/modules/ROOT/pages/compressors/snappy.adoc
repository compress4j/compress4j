= Snappy

Snappy support needs no extra dependency. Compress4J provides two stream types, because they are different formats: the framed format (`.sz`, used for files and streams) and the raw format, a single block.

The raw format stores the uncompressed length first, so `SnappyRawCompressor.builder(...)` requires it as an argument and rejects a negative value with an `IllegalArgumentException`.
