= LZ4

LZ4 support needs no extra dependency. Compress4J provides two stream types, because they are different formats: the framed format (the `.lz4` files written by the `lz4` command line tool) and the raw block format.

The framed decompressor can read concatenated frames when `setDecompressConcatenated(true)` is set.

NOTE: Closing a block LZ4 compressor without writing any data fails inside Commons Compress with an `IndexOutOfBoundsException`. Write at least one byte before closing it.
