= Migrating from 3.x to 4.0

Version 4.0 moves Compress4J from `io.github.compress4j` to `com.hominux`. The API is unchanged apart from the names below.

== Dependency

Replace the group:

[source,kotlin]
----
implementation("com.hominux:compress4j:4.0.0")
----

Builds that keep `io.github.compress4j:compress4j:4.0.0` resolve to the new coordinates through a relocation POM.

== Packages

Replace the package prefix `io.github.compress4j` with `com.hominux.compress4j` in imports.

== Module name

The JPMS module is now `com.hominux.compress4j`. Update `requires io.github.compress4j;` in your `module-info.java`.
